# Inventory Management System

A full-stack inventory management application designed to help organizations track shared inventory across users and locations.

I originally built this project to solve a real-world inventory management need. The system is designed for use by organizations such as the University of Utah Honors College and ICO, with an emphasis on simple organization, shared access, and accountability.

## Features

- User registration and login
- Create or join an organization using a company code
- Organization-based inventory separation
- Admin and member roles
- Multiple inventory locations
- Add and manage inventory items
- Shared inventory access for organization members
- User activity tracking
- Admin tools for managing organization members
- Ability for administrators to review and revert a user's changes from a selected date
- Persistent cloud-hosted database

## Why I Built It

Inventory information is often scattered between spreadsheets, individual employees, and separate systems. I wanted to build a practical tool that gives an organization one shared place to manage inventory while still maintaining user accountability and administrative control.

This project allowed me to work through the full development process, including database design, authentication, role-based permissions, front-end development, API development, and deployment configuration.

## Status

The core inventory management system is complete and functional. The application was built as a portfolio project with real-world organizational use in mind.
